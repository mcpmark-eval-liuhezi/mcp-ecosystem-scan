# mcp-ecosystem-scan
Live scan of the Model Context Protocol (MCP) ecosystem: top repositories, SDK usage in real code, and open-issue pain points.

## Purpose

This repository exists to capture, in one reviewable place, our team's quarterly evaluation of the Model Context Protocol ecosystem. The research previously lived scattered across browser tabs; here it is recorded as a reproducible snapshot — the top MCP repositories by GitHub search with their star counts, where the official Python SDK actually shows up in real-world code, and the themes emerging from open issues across the ecosystem. The findings are tracked in `docs/ecosystem-snapshot.md` and reviewed through pull requests, with per-project adoption-check issues for the leading repositories, so the whole team can review, comment on, and build on the same evidence base.
